# 🔐 Cyber Security Attack Analysis Dashboard (Power BI)

## 📌 Overview

This project presents an interactive **Cyber Security Dashboard** built using Power BI to analyze global cyber attack trends.
The dashboard helps identify patterns, high-risk periods, and key insights to support better security decisions.

---

## 🎯 Objective

* Analyze cyber attack trends over time
* Identify peak attack years and patterns
* Understand distribution of attacks across categories
* Provide actionable insights for cybersecurity awareness

---

## 🛠️ Tools & Technologies

* 📊 Power BI
* 🔄 Power Query (Data Cleaning & Transformation)
* 📐 DAX (Data Analysis Expressions)
* 📁 Dataset (CSV/Excel)

---

## 📊 Key Features

* Interactive dashboard with filters and slicers
* Year-wise analysis of cyber attacks
* Category-wise attack distribution
* Trend visualization using line charts
* KPI indicators for quick insights

---

## 📈 Key Insights

* Significant spike in cyber attacks observed around **2017**
* Certain attack categories dominate overall incidents
* Increasing trend highlights growing cybersecurity threats
* Data-driven insights can help in proactive risk management
